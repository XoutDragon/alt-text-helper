# Alternative Text Helper

### What is this?

This project aims to make websites more accessible to people with visual impairments, need extra learning, and disabilities.

### Why is this a problem?

50% of users that have visual impairments misinterpret non-text content. [Source](https://worldmetrics.org/web-accessibility-statistics/)

### Our approach

We used Python and the AI model quen.

There is a main file that initializes our AI bot and calls each of our processes.
